10G/25G Ethernet (MRMAC) Ref Designs for Quad SFP28 FMC
=======================================================

This is the documentation for the 10G/25G Ethernet reference designs for the Opsero `Quad SFP28 FMC`_.
The designs use the Versal Integrated 100G Multirate Ethernet MAC (MRMAC) to drive each of the
four SFP28 ports as an independent 10GbE or 25GbE channel.
